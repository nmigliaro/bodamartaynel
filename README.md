# Marta y Nelson

Static export of the six public pages, original site fonts, and public images from the former IONOS-hosted wedding website.

## Local preview

Serve this directory with any static web server. On the Nginx server, the site is published under `/bodamartaynel/`.

## Migration notes

- The RSVP button still opens the original Google Form; its availability and response storage remain with Google.
- Google Maps are loaded only after selecting "Acepto" in the map consent notice. The original translation widget is not included.
- The legal notice and privacy page retain the original placeholder text and should be reviewed before public use.
- This is a static copy of public pages, not an export of the WordPress database, admin account, or editable IONOS/WordPress project.
